#Airbnb-Analytics-Project


##📖 Project Overview

This project is an end-to-end Data Analytics project using the Airbnb New York dataset.

The objective is to transform raw Airbnb data into meaningful business insights through data modeling, SQL analysis, and interactive Power BI dashboards.

---

## 🎯 Business Goal

The goal of this project is to help Airbnb managers understand:

- Listing performance
- Price distribution
- Popular locations
- Host activity
- Availability trends
- Customer review patterns
